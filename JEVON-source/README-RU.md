# JEVON — исходники для Visual Studio Code

Снимок исходников от 3 октября 2026 года. Три самостоятельных проекта:

- jevon-order-status — статусы заказов и кабинеты сотрудников.
- jevon-order-tracking — просмотр заказа клиентом.
- jevon-hastu-nest — регистрация прихода и ухода работников.

## Как открыть

1. Распакуйте архив полностью.
2. Установите Node.js версии 22.13 или выше и Visual Studio Code.
3. В VS Code выберите «Файл → Открыть рабочую область из файла» и откройте JEVON.code-workspace.
4. Откройте терминал в папке нужного проекта.
5. Установите зависимости и запустите локальный сайт:

```powershell
npx --yes pnpm@11.25.0 install --frozen-lockfile
npx --yes pnpm@11.25.0 dev
```

Откройте адрес, показанный в терминале (обычно http://localhost:5173). Запускайте по одному проекту: по умолчанию они используют один порт. Для другого порта добавьте `--port 5174` к команде dev.

## Где менять код

- app/page.tsx — основная страница.
- app/globals.css — основные стили.
- app/api/ — серверные обработчики.
- components/ — компоненты интерфейса.
- db/schema.ts и drizzle/ — схема базы и SQL-миграции.
- public/ — статические файлы.
- package.json — зависимости и команды проекта.

## Что нужно для полной работы

Это исходники, а не резервная копия рабочих баз. Заказы, учётные записи, фотографии, серверные секреты и данные посещаемости в архив не включены. Cloudflare D1/R2 и внешние интеграции требуют отдельной настройки; чистый локальный запуск может показывать пустые данные или ошибки API до этой настройки. Структура базы сохранена в SQL-миграциях.

В проектах сохранены исходные настройки Sites и файлы блокировки зависимостей. Профиль запуска на обычном компьютере автоматически выбирается portable. Производственная авторизация может отличаться от локальной заглушки.

Сборка:

```powershell
npx --yes pnpm@11.25.0 build
```

Этот архив не проходил установку зависимостей и запуск на Windows; проверена целостность экспортированных файлов. Изменения в VS Code не обновляют опубликованный сайт автоматически. Для публикации требуется отдельный шаг.
